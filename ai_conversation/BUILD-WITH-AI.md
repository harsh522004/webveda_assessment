AI Conversation
===============

This folder contains the AI conversations used during the development of the Skillpath project.

I used AI as an assistant throughout the process --- from understanding Framer for the first time, to exploring implementation approaches, writing React code, debugging issues, discussing design decisions, and generating visual assets.

The conversations are included to provide context on how AI was used during the project and how the implementation evolved.

AI Usage
--------

### 1\. GPT

I prefer GPT when I need:

-   Conceptual understanding

-   Asking questions and discussing ideas

-   Suggestions and alternative approaches

-   Image generation and visual exploration

**Reference:** `Framer_Understanding.pdf`

This was the first conversation I started when I came across the word **Framer** in the assessment and wanted to understand what Framer was and how it would be used for this assignment.

* * * * *

### 2\. Gemini

I prefer Gemini mainly for:

-   React code generation

-   Tasks that require the latest information

-   Framer Editor-related tasks

-   Longer conversations where maintaining context is important

**References:**

-   `Basic_Framer_Component.pdf` --- My first hands-on learning with the Framer Editor. I started with a simple Todo rendering using hardcoded data to get familiar with Framer Code Components.

-   `Assessment_Gemini_Master_1.pdf` --- The main conversation containing most of the discussions while building the Skillpath website.

-   `Framer_Layout_Responsivness_Issue.pdf` --- Discussion around vertical alignment and responsive layout issues.

* * * * *

### 3\. Perplexity

I used Perplexity occasionally when I needed quick access to current information from the internet, especially when I got stuck with a small Framer UI or implementation-related question.

Why These Conversations Are Included
------------------------------------

The conversations show the learning and development process behind the project, including:

-   Understanding Framer and its workflow

-   Exploring different implementation approaches

-   Building the first simple Code Component

-   Developing the actual Courses section

-   Debugging layout and responsiveness issues

-   Discussing implementation and design decisions

-   Reviewing and improving the final code

The goal is to keep the AI-assisted development process transparent and provide the actual conversation context behind the work.

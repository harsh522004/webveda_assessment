### Note

I built Skillpath as a Framer learning-platform landing page, with a React Code Component powering the live course catalogue and handling API data, currency logic, loading, error, and empty states.

My main focus was understanding the requirements and priorities first, then implementing the React Code Component around the API and its different states. I also spent time getting familiar with the Framer Editor and its layers, frames, and properties.

The biggest learning curve was Framer, as this was my first time working with a design editor. Alignment also took time because React and Framer have their own layout and styling behavior, so I had to understand how they work together. I initially reused a free template for the top navigation, but later found that its master wrapper structure made some layout changes harder to understand.

I am still not fully happy with the vertical alignment across all sections.

With two more days, I would improve responsiveness, refine the UI for error and empty states, and add optional features such as search and filtering by category, price, and type.

I used GPT for conceptual understanding, questions, suggestions, and visuals; Gemini mainly for code generation and Framer-related work; and Perplexity occasionally for current information and small Framer questions. The actual conversations are included in the repository.
